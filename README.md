# CSE3100 - Systems Programming

This repository contains coursework and programming assignments from CSE 3100: Systems Programming at the University of Connecticut.

The course provides an introduction to system-level programming with an emphasis on C programming, process management, concurrency, memory management, and debugging.

Topics Covered
C programming
System-level programming
Process management
Multithreaded programming
Small-scale concurrency
Memory management
Pointers and dynamic memory
Sequential and parallel programming
Debugging and troubleshooting
Technologies
C
Linux/Unix
GCC
GDB
Make
About the Course

CSE 3100 focuses on understanding how programs interact with the operating system and how software behaves at the system level. Particular attention is given to managing memory, working with processes and threads, and identifying and debugging problems in both sequential and parallel programs.

Repository Contents

This repository includes programming assignments, labs, and other coursework completed throughout the semester.
